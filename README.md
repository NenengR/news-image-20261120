# make.fun news-image-20261120

A Node 22 program (stdlib only, deterministic) that renders a procedural newspaper front page — "Sum up 20 November's world news in one image" — and writes `out/entry.png` (1024×1024, under 1 MiB).

## Five stories

- **SUMMIT** — TRUMP, XI, PUTIN SIGN PEACE PACT — DECLARATION AFTER SHENZHEN SUMMIT
- **UKRAINE** — UK SENDS 1,000 DRONES — 260 MILLION POUND AID PACKAGE
- **CYBER** — US CYBER CHIEF FIRED — AFTER NATIONWIDE OUTAGES
- **TECH** — ANTHROPIC SOARS 34 PERCENT — 2 TRILLION DOLLAR DEBUT
- **EUROPE** — UK-EU YOUTH DEAL AGREED — MOBILITY SCHEME SEALED

Layout: one full-width lead panel, four smaller story panels in a 2x2 grid, masthead and footer. Own PNG encoder via zlib, embedded 5x7 bitmap font.
